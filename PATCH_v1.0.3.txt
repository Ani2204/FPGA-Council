WHAT CAUSED THIS:
-----------------

LLMs (even with JSON mode) sometimes return slightly different
field names in their JSON output. For example:

Expected:
{
  "modules": [{
    "module_name": "uart_tx",
    "verilog_code": "module uart_tx..."
  }]
}

But Got:
{
  "modules": [{
    "name": "uart_tx",           ← Different key!
    "code": "module uart_tx..."  ← Different key!
  }]
}

The original code assumed exact field names, causing crashes.
The fix handles all reasonable variations gracefully.
