Workflow Stages
===============

Stage 0: Idea Validation
  - HOD validates feasibility and gathers constraints
  - Output: stage0_validation.json

Stage 1: Requirement Freeze
  - HOD creates frozen specification with exact parameters
  - Output: stage1_requirements.json
  - Gate: Must be approved to proceed

Stage 2: Architecture Design
  - Architecture role designs block diagram and FSMs
  - Output: stage2_architecture.json

Stage 3: Architecture Approval
  - HOD approves or rejects architecture
  - Output: stage3_approval.json
  - Gate: Must be approved to proceed

Stage 4: RTL Generation
  - RTL role generates synthesizable Verilog
  - Output: stage4_rtl.json + *.v files

Stage 5: Verification Audit
  - Toolchain validation (Yosys, Verilator)
  - Verification role audits and fixes errors
  - Auto-fix loop (up to 3 iterations)
  - Output: stage5_verification.json + *_verified.v files
  - Gate: Must pass to proceed

Stage 6: System Feasibility
  - System role analyzes resources, timing, risks
  - Output: stage6_system.json

Stage 7: Final Approval
  - HOD final GO/NO-GO decision
  - Output: stage7_final_approval.json
  - Gate: Production readiness check


Role Responsibilities
======================

HOD (Head of Design)
  - Master orchestrator and decision authority
  - Validates ideas and feasibility
  - Freezes requirements (no ambiguity)
  - Approves/rejects at gate points
  - Final production approval
  - NO implementation authority

Architecture Designer
  - Designs block diagrams
  - Creates FSM specifications
  - Defines interfaces and signals
  - Plans data paths
  - NO CODE GENERATION

RTL Engineer
  - Generates synthesizable Verilog
  - Implements exact architecture
  - Follows coding standards
  - ONLY writes code

Verification Engineer
  - Audits RTL for correctness
  - Runs toolchain validation
  - Fixes synthesis/lint errors
  - Ensures best practices

System Engineer
  - Estimates resources (LUTs, FFs, BRAMs)
  - Analyzes timing feasibility
  - Assesses implementation risks
  - Recommends FPGA families
